01

Overview

The objective of this task is to understand cloud-based IoT communication and how an IoT device can interact with a dashboard through an online IoT platform.

During Week 7, I configured Adafruit IO feeds and dashboards and worked with Arduino IDE C code to control a bulb remotely through the IoT setup.

02

Concepts

Adafruit IO

A cloud-based platform used for connecting devices, feeds and dashboards.

MQTT

A lightweight messaging protocol commonly used for IoT device communication.

Feed

A logical data channel used to exchange IoT information through the cloud platform.

Dashboard

A visual interface used to monitor or control IoT data and devices.
