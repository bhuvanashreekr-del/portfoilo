Adafruit IO Dashboard & MQTT

Understanding cloud-based IoT communication using Adafruit IO, feeds, dashboards and MQTT concepts.

01

Overview

The objective of this assignment was to understand how an IoT device can communicate with a cloud platform and how a dashboard can be used to monitor or control the device.

During my Week 7 IoT work, I configured Adafruit IO feeds and dashboards and used Arduino IDE C code as part of the ESP32-based bulb-control workflow.

02

Concepts

Adafruit IO

A cloud-based IoT platform that provides feeds and dashboards for connecting and interacting with devices.

MQTT

A lightweight messaging protocol commonly used for communication between IoT devices and cloud services.

Feed

A communication channel used to exchange IoT values through the cloud platform.

Dashboard

A visual interface containing controls or displays connected to IoT feeds.

06

Implementation Process

Step 1 — Understanding Cloud-Based IoT

I first understood the difference between local device control and cloud-based IoT communication. I learned how an IoT device can exchange information through an online platform.

Step 2 — Setting Up Adafruit IO

I accessed Adafruit IO and explored its dashboard and feed structure. I studied how feeds can act as communication channels between an IoT device and the cloud platform.

Step 3 — Creating the Feed

I configured the required feed for the IoT control process. The feed was used to represent the control information exchanged through the cloud platform.

Step 4 — Creating the Dashboard

I created the Adafruit IO dashboard and added the required control interface. This provided a visual way to interact with the IoT system.

Step 5 — Understanding MQTT

I studied the basic MQTT communication model and understood the roles of publisher, subscriber, broker and topic/feed in IoT communication.

Step 6 — Programming the ESP32

I used Arduino IDE to program the ESP32 and prepare it for communication with the Adafruit IO platform.

Step 7 — Connecting the Dashboard and Hardware

I connected the dashboard control with the corresponding IoT feed and configured the ESP32 to respond to the received control value.

Step 8 — Testing the Cloud Control

I operated the dashboard control and observed the connected bulb response. I tested the control operation to verify that the cloud command was reaching the hardware correctly.

Step 9 — Final Verification

After confirming the operation, I captured the Adafruit IO dashboard and bulb-control screenshots as evidence.
