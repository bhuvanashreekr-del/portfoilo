ESP32 Web Server & HTML LED Control

A practical exploration of using an ESP32 as a local web server and controlling connected hardware through a web-based interface.

01

Overview

The objective of this task is to understand how an ESP32 can operate as a local web server and provide a browser-based interface for controlling connected hardware.

My Week 7 IoT work included an ESP32 Local Web Server where the ESP32 was used to create a local HTTP web interface for controlling LEDs and relay-driven bulbs.

02

Concepts

ESP32

A microcontroller platform capable of Wi-Fi networking and hardware control.

Web Server

A program running on the ESP32 that responds to browser requests through HTTP.

HTML Interface

A browser-based interface can provide buttons or controls for interacting with the connected hardware.

Local Communication

The ESP32 and controlling device communicate through the local network.
