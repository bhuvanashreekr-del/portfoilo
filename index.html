Webrivex — a client intake platform, built solo

Not a template project. A branded product designed, built, secured, and shipped from scratch.

From brand identity to a locked-down database

Webrivex is a full-stack client-intake web application built independently — brand identity and visual system first, then a multi-step intake form driven by service-based logic, a Supabase backend with authentication, and Row-Level Security enforced at the database layer so clients can only ever see their own data.

Submissions trigger real-time notifications through Formspree, and the whole product is deployed to production on Netlify.
