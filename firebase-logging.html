TASK 05 · IoT LEARNING

Firebase Logging, Automation & Data Export

Understanding how an IoT system can collect information, store historical data, automate device control and present information through a cloud-connected dashboard.

01

Overview

This assignment focuses on the architecture of a cloud-connected IoT system where device information can be collected, stored, monitored and used for automation.

The process involves connecting an IoT device with Firebase, organising the collected information and presenting the stored information through a dashboard.

The current Week 7 evidence does not establish a completed DHT11/LDR historical logging and CSV export implementation. Therefore, unsupported completed-work claims have not been added.
02

Concepts

Data Logging

Recording device information over time so that it can later be reviewed and analysed.

Historical Data

Previously recorded information stored for later viewing and analysis.

Automation

Automatically performing an action when a defined condition is satisfied.

Data Export

Converting stored information into a reusable format such as CSV.

Step 3 — Understanding Firebase Data Storage

I studied how IoT information can be organised and stored in Firebase so that previously recorded values can later be retrieved by a dashboard.

Step 4 — Planning Historical Records

I understood the importance of associating each recorded value with a timestamp so that changes in the IoT system can be analysed over time.

Step 5 — Understanding Manual and Automatic Control

I studied how an IoT system can provide manual control through a dashboard as well as automatic control based on sensor conditions.
