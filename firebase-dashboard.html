Authentication

Authentication verifies the identity of a user attempting to access an application.

Authorization

06

Implementation Process

Step 1 — Understanding the Requirement

I first understood how Firebase could be used as a cloud platform for a web application and how authentication could be used to control access to the application.

Step 2 — Creating the Web Application

I started by creating the responsive landing page and developing the HTML, CSS and JavaScript structure required for the application.

Step 3 — Configuring Firebase

I connected the web application with Firebase and prepared the required Firebase services for the project.

Step 4 — Implementing Authentication

I configured Firebase Email/Password Authentication so that users could sign in to the application using their credentials.

Step 5 — Creating the Login Flow

I created the login interface and connected it with Firebase Authentication. I then tested the authentication process using the available login credentials.

Step 6 — Protecting the Dashboard

I used authentication-state handling to determine whether the user was authenticated. Based on the authentication state, access to the dashboard was controlled.

Step 7 — Implementing Logout

I added logout functionality so that an authenticated user could sign out and leave the protected dashboard.

Step 8 — Testing

I tested the complete flow by checking the landing page, login process, authentication state, dashboard access and logout functionality.

Step 9 — Hosting

I also worked with the Firebase Hosting CLI as part of the deployment workflow for the web application.
